Premisas para la instalación de la SIM Virtual ETB

1. Requisitos para la instalación

  • Contar con un teléfono móvil compatible con la tecnología SIM Virtual.
  • Tener conexión a internet mediante una red Wi-Fi para realizar la instalación.
  • Disponer del código QR necesario para descargar la SIM Virtual.

2. Pasos para instalar la SIM Virtual

Si el equipo es Android
  1. Conéctese a una red Wi-Fi.
  2. Ingrese a la opción Configuración y seleccione Conexiones.
  3. Ingrese a Administrador de tarjetas SIM.
  4. Seleccione Agregar plan móvil.
  5. Elija la opción para escanear el código QR y realice la lectura.
  6. Una vez leído el código, seleccione la opción para añadirlo y utilizarlo.
Si el equipo es iPhone
  1. Ingrese a Configuración.
  2. Seleccione Datos celulares.
  3. Elija la opción Agregar plan de datos móviles.
  4. Cuando se habilite el escáner, realice la lectura del código QR.
  5. Seleccione nuevamente Agregar plan de datos móviles para completar el proceso.
  6. Verifique que aparezca el perfil eSIM activo, junto con la línea y el plan habilitado.

3. Recomendaciones si presenta inconvenientes

Si presenta dificultades durante la instalación:

  • Reiniciar el dispositivo una vez finalizada la instalación.
  • Verificar si el teléfono requiere actualizaciones del sistema operativo.
